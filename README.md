## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, выбрав любой вариант, кроме "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (поставщик Cloudflare может оказаться заблокирован)
    * В Windows 11 Secure DNS можно активировать непосредственно в настройках системы — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это предпочтительный способ
    * Владельцам роутеров Keenetic нужно включить в настройках пункт "Транзит запросов". При отключённой опции Secure DNS на компьютере может работать некорректно

2. Получите zip/rar-архив с [последнего релиза](https://github.com/TitanBunting/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Извлеките файлы в каталог, в пути которого нет кириллицы и специальных символов

5. Запустите нужный скрипт
    * Проверить рабочую стратегию можно через **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для установки стратегии в автозапуск откройте **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — запуск выбранной стратегии вручную

  Такой запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому **перебирайте варианты (ALT, FAKE и другие), пока не найдёте подходящий именно для вас**

- [**`service.bat`**](./service.bat) — автозапуск стратегии и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из списка служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние (включено или выключено) отображается в скобках.
  - **`IPSet Filter`** — включить или изменить обход сервисов, перечисленных в `ipset-all.txt`.  
  Этот параметр пригодится при проверке ресурса, который без zapret работает, а с ним — нет  
  В скобках отображается текущий режим:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — адрес проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый fake на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare, Amazon и других


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый в панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/TitanBunting/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого Блокнота
  - Откройте файл `hosts` в появившемся каталоге через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированные строки в конец `hosts` (либо замените ими ранее добавленные аналогичные строки)
  - Сохраните файл и проверьте соединение ещё раз. Если проблема осталась, убедитесь, что изменения действительно сохранены.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/TitanBunting/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение определённой стратегии может произойти не сразу: какое-то время она работает, а затем перестаёт.
> В репозитории собрано много вариантов обхода. Если готовые варианты не помогают, создайте собственную стратегию на базе одной из них, изменив её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках

- Проверьте, присутствует ли адрес нужного ресурса в списках доменов или IP

- Переключитесь на другие варианты (**`ALT`**, **`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/TitanBunting/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните ресурсы и данные, которые добавляли самостоятельно
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Откройте `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их и в конце нажмите Y
- Удалите старую папку с zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/TitanBunting/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, отметьте его, нажмите применить, затем ОК
- Распакуйте архив в новую папку в корне диска, избегая пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте доступ к интернет-ресурсам. Если вариант не работает, закройте программу через значок замка в панели задач и попробуйте следующую стратегию
- После выбора рабочей стратегии установите её в автозапуск через `service.bat` -> `Install Service` -> выберите нужный вариант

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` — в **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Инструкция доступна здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив полученное имя в обе команды:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежняя стратегия больше не помогает, переберите остальные варианты.
- См. также [#251](https://github.com/TitanBunting/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно выяснить, на какой стратегии открывается YouTube, и запустить именно её.
- В `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте приложение Discord после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею.
- Если браузер также не подключается, снова проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/TitanBunting/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/TitanBunting/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальную последовательность:
- в `service.bat` обновите ipset и включите `Game Filter`
- если результата нет, дополнительно активируйте `ipset any`

Имейте в виду: режим `ipset any` способен нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Лучше определить все IP-адреса, которые использует игра, и внести их в `ipset-all.txt`

Если это не помогло, создайте обсуждение в разделе [Discussions](https://github.com/TitanBunting/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/TitanBunting/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети уже есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
